# Locked research dataset

No empirical dataset is committed to this directory by default.

The final research deposit must be generated from the same locked 993-row evaluation snapshot used for the reported 30 September evaluation. Before any dataset is added here or uploaded to GitHub, confirm that:

1. the records are deidentified and contain no prohibited personal or contact information;
2. every source permits the proposed form of redistribution;
3. the deposited file, manifest, split membership, retained predictions and evaluation artefacts refer to the same snapshot;
4. the ethics and institutional repository conditions are satisfied; and
5. the SHA-256 digest is recorded in the release register.

If any source does not permit public redistribution, keep the dataset out of GitHub and deposit it through the appropriate restricted-access examiner/eSango channel. Publish only the metadata, rights statement and access procedure here.
