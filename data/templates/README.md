# Research-data templates

This directory contains schemas and empty/example registers used to assemble a governed research dataset. Files here are not empirical evidence and must not be reported as observations.

The templates cover:

- source rights and immutable source/version metadata;
- curriculum and vacancy records;
- vacancy deduplication decisions;
- monthly collection coverage;
- skill-taxonomy versions;
- alignment coding and eligibility decisions;
- split membership; and
- the dataset manifest.

Canonical alignment and forecasting observation schemas are located in `research_evaluation/schemas/`.

Populate these templates only in authorised research storage after confirming ethics, custodian and source-rights conditions. The final frozen dataset belongs in `data/locked/` only when its permitted access classification is documented. A restricted dataset must not be committed to the public GitHub repository.
